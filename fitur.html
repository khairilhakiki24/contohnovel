PWA Serverless Edition

Platform Membaca
Tanpa Biaya Server.

Sistem web progresif (PWA) cerdas yang membajak ("nebeng") kekuatan infrastruktur Google (Blogger) sebagai CMS Utama, dikombinasikan dengan IndexedDB untuk pengalaman membaca secepat kilat dan bisa diakses luring (offline).

Bagaimana Kami Menghemat Puluhan Juta?

Sistem KaryaKita didesain untuk menghilangkan seluruh titik pengeluaran infrastruktur tradisional (Backend & Database) tanpa mengorbankan performa.

Per Tahun

Nebeng Server Raksasa Google

Ribuan hingga jutaan *traffic* pengguna tidak akan membuat server down. Data ditarik langsung dari infrastruktur Google (Blogger) yang terdesentralisasi secara global secara gratis.

Anti-CORS via Teknik JSONP

Kita dapat mengambil data dari domain mana saja (LINTAS DOMAIN) tanpa diblokir sistem keamanan browser dengan menyuntikkan script tag dinamis via `fetchBloggerJSONP()`.

Zero-Cost Database via IndexedDB

Setiap cerita yang ditarik akan langsung di-cache ke dalam `Dexie.js` di memori perangkat pembaca. Mengurangi request server dan memungkinkan membaca luring 100%.

Fitur Utama Sistem

Pembagian tugas yang sangat efisien antara dua workspace utama.

Admin Workspace (admin.html)

  • Keamanan Klien-Murni: PIN akses disimpan lokal di browser. Mustahil di-hack via server karena server backend tidak ada.
  • Multi-Source RSS: Bisa menggabungkan banyak link RSS/XML (dari Blogger, WP, Feed external) ke dalam 1 kategori (misal: "Romantis").
  • Dukungan Penulis: Bisa menyisipkan tautan Trakteer/Saweria khusus untuk setiap sumber RSS, yang akan muncul otomatis di akhir cerita penulis terkait.
  • Generator JSON Instan: Hanya 1 klik mengubah semua *settingan* (Banner, Tema, Menu) menjadi *string JSON* yang siap ditaruh di Blogger.

Client Reader App (index.html)

  • Auto-Ranking Kontributor: Mesin otomatis mendeteksi tag `author` dari RSS dan memberikan peringkat (medali emas, perak, perunggu) berdasar rilis terbanyak.
  • Smart Chapters (Bab Otomatis): Algoritma RegExp memisahkan judul dasar. Jika ada "Novel A - Bab 1" dan "Bab 2", UI otomatis membuat dropdown daftar bab.
  • Personalisasi Premium: 5 ukuran teks, dan integrasi Google Fonts khusus literasi (Merriweather, Lora, Playfair) dengan Focus Mode.
  • Live Search Memory: Pencarian cerita, penulis, atau genre secara instan tanpa loading internet, karena menelusuri IndexedDB RAM secara langsung.
Teknologi Unggulan

Swipe Engine: Mode Buku Sesungguhnya

Bagaimana HTML panjang bisa dipotong presisi menjadi halaman-halaman yang dapat digeser kiri-kanan bak membaca buku nyata tanpa *backend parser*?

  • 1

    CSS Multiple Columns

    Memanfaatkan column-width: 100vw; yang memaksa browser membagi teks panjang menjadi kolom selebar layar perangkat secara dinamis.

  • 2

    Anti Terpotong (Break-Inside)

    Gambar dan paragraf dikunci dengan break-inside: avoid-column agar tidak terbagi dua antar halaman yang berbeda.

  • 3

    JS Gestures & Tap Zones

    Menerapkan transform: translate3d pada saat swipe. Mendukung efek 'membal' khas iOS, dan memiliki 3 Tap Zones (Kiri: Mundur, Tengah: Fokus, Kanan: Maju).
